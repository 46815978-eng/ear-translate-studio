# 哇学社商用迁移指南

## 1. Edge-TTS → 商用 TTS 替换

| 当前方案 | 商用替代 | 预算 | 备注 |
|---------|---------|------|------|
| Edge-TTS (免费但不可商用) | 阿里云智能语音合成 | 按量计费 | 支持中英文，音质更好 |
| | 腾讯云语音合成 | 按量计费 | 微信生态集成好 |
| | 科大讯飞语音合成 | 按量计费 | 教育行业主流选择 |

迁移步骤：
1. 取消 `backend/tasks/audio_tasks.py` 中 edge_tts 调用
2. 接入目标 TTS SDK，修改 `generate_tts_audio` 任务
3. 音频文件从本地存储迁移到云存储

## 2. MinIO → 阿里云OSS/腾讯COS

| 当前方案 | 商用替代 | 优势 |
|---------|---------|------|
| MinIO (本地存储) | 阿里云OSS | CDN加速、高可用 |
| | 腾讯云COS | 微信生态集成 |
| | AWS S3 | 全球部署 |

迁移要点：
- `docker-compose.yml` 中移除 minio 服务
- `backend/config.py` 替换 MinIO 配置为 OSS/COS SDK 配置
- 用户头像、课程封面、音频文件全部迁移

## 3. LibreTranslate → 正式翻译服务

| 当前方案 | 商用替代 | 优势 |
|---------|---------|------|
| LibreTranslate (离线) | 腾讯云翻译API | 准确度高 |
| | 阿里云机器翻译 | 教育行业专项模型 |
| | DeepL API | 欧洲语言最优 |

## 4. 数据库优化

- MySQL 单机 → RDS 主从架构
- Redis → Redis 集群（缓存+Session+消息队列）
- 分表分库策略（按用户ID hash）
- 读写分离（主库写、从库读）

## 5. 部署与CDN

- Docker Swarm / K8s 容器编排
- Nginx 反向代理 + 负载均衡
- 阿里云CDN / 腾讯云CDN 加速静态资源
- WAF 安全防护

## 6. 域名与备案

- 购买域名（如 woxueshe.com）
- ICP 备案
- 配置 SSL 证书（HTTPS）
- 小程序域名校验

## 7. 支付集成

| 当前方案 | 商用替代 |
|---------|---------|
| 沙箱支付 | 微信支付商户平台 |
| | 支付宝支付 |

需完成：
- 企业认证
- 商户号申请
- 支付回调地址配置
- 退款流程

## 8. 消息推送

- 极光推送 / 腾讯信鸽
- 微信模板消息
- APP 内通知

## 9. 监控与告警

- 阿里云 ARMS / 腾讯云 CAT
- 日志：ELK Stack / 腾讯云日志服务
- 崩溃监控：Firebase Crashlytics / Bugly
- 性能监控：APM 工具

## 10. 合规与安全

- 用户协议 & 隐私政策
- 实名认证（未成年保护）
- 数据加密（AES-256）
- 等保认证
- GDPR / 《个人信息保护法》合规

---

> **注意**：本迁移文档适用于产品从 MVP 阶段转向商业化运营的场景。
> 初期 MVP 阶段（<1000用户）可继续使用当前本地方案+免费额度。
